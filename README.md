# SSC Hackathon Submission

Super Incredibly Simple TPRM Dashboard

Link to spreadsheet: https://docs.google.com/spreadsheets/d/1oWzuKSRW61T0Yqo8mWgMnzUCkoIxBwormAXgOJeuQdM/edit?gid=0#gid=0

Attached is a basic prototype of a TPRM (Third-Party Risk Management) Dashboard created by integrating SSC's API with Google Sheets.

The goal of this project is to offer a TPRM dashboard that’s user-friendly, customizable, and provides a quick overview at a glance.

You can tailor the dashboard to display companies with a specific letter grade you want to track, those that experienced breaches within a certain timeframe, or those affected by particular CVEs.

The idea is to create a widely accessible TPRM tool that can be easily checked and give you a brief background while enjoying your coffee or tea at your convenience without the need to deep dive into complex reports.

The sheet only has a limited amount of functions but can further be improved on if new, specific use cases arise.
